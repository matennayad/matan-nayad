# מטוס A320 בתלת-ממד

נפתח בכתובת האתר עם `#a320`.

דגמי תא הטייס והמטוס לקוחים מ-[FlightGear A320-family](https://github.com/legoboyvdlp/A320-family), של Josh Davidson, Jonathan Redpath ושותפים, ברישיון GPL-2.0 (ראו `LICENSE.txt`). ההמרה לפורמט glTF נעשתה על ידי czkai9010/a320-trainer-models.

השינויים שנעשו בדגמים: הם הומרו, נדחסו וחולקו לקבצים `m_*.js`. תא הנוסעים, הצביעה ושדה התעופה נבנו בקוד.
