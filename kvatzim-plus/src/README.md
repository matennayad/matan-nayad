# קבצים פלוס – דף הנחיתה

הדף נפתח בכתובת https://matennayad.github.io/matan-nayad/#kvatzim-plus

## לשנות מילה או משפט (הדרך הקלה)
1. פותחים ב-GitHub את הקובץ `kvatzim-plus/shell.js`.
2. לוחצים על העיפרון ✏️ (Edit) בצד ימין למעלה.
3. מחפשים את הטקסט עם Ctrl+F, ומשנים אותו.
4. לוחצים **Commit changes** (הירוק). אחרי דקה-שתיים השינוי באתר (לפעמים צריך Ctrl+F5).

רק שלושה דברים לא לגעת בהם:
- התו `` ` `` בתחילת הדף (אחרי `String.raw`) ובסוף הקובץ.
- תגיות בסוגריים משולשים, כמו `<b>` ו-`</span>` – משנים רק את הטקסט שביניהן.
- לא לכתוב בטקסט את התו `` ` `` או את הצירוף `${`.

## שינויים גדולים יותר
הקבצים בתיקייה הזו הם המקור שממנו `shell.js` נבנה:
- `page.tpl.html` – מבנה הדף, העיצוב והטקסטים.
- `mocks.py` – "צילומי המסך" של התוסף, בנויים ב-HTML (בלי קבצי תמונה), כולל השמות המומצאים.
- `build.py` – בונה מהם את `shell.js`. הרצה מתיקיית הריפו: `python3 kvatzim-plus/src/build.py`

שימו לב: הרצת `build.py` דורסת את `shell.js`. אם שיניתם טקסט ישירות ב-`shell.js`, שנו אותו גם ב-`page.tpl.html` (או ב-`mocks.py`) לפני שבונים מחדש.

## מדריך ההתקנה (#install)
`kvatzim-plus/install.js` מכיל את "מדריך טעינת תוסף לכרום" (HTML מלא עם הצילומים), והוא נפתח בכתובת
https://matennayad.github.io/matan-nayad/#install
הקישור הזה מופיע גם במיילים שהשרת שולח לחברים (הגדרה "קישור למדריך ההתקנה").
