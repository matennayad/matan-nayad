# מטען נייד – בניית אתרים ואפליקציות

אתר פרסומת סטטי (קובץ `index.html` אחד), מוכן לפרסום ב-GitHub Pages.

## עדכון פרטי קשר
בתחתית `index.html` יש אובייקט `CONFIG` – מעדכנים בו טלפון, מספר וואטסאפ ומייל.

## פרסום ב-GitHub Pages
1. מעלים את הקבצים לריפו ב-GitHub.
2. Settings → Pages → Source: `Deploy from a branch`, Branch: `main`, תיקייה `/ (root)`.
3. אחרי דקה-שתיים האתר זמין בכתובת `https://<username>.github.io/<repo>/`.
